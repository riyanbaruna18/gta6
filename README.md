SOLMARA is a 2D top-down open-world crime game: steal a car, outrun the Solmara police, and run five missions for Rico Vega and Mama Luz — from First Wheels to The Big Score, cracking the Solmara Bank vault and escaping to the beach. A seeded city (Palma Park, the docks, the beach), traffic and pedestrians, a wanted system up to five stars, police cars and foot patrols, a live minimap, synthesized WebAudio, and a localStorage save. Plain canvas and ES modules, no libraries and no network requests — it plays offline in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
